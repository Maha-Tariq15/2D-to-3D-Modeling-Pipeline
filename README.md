# 2D to 3D Modeling and Animation Pipeline

## Overview
This project implements a pipeline for transforming 2D inputs into 3D models and creating animation sequences.

The project explores concepts from:
- Computer Vision
- 3D Modeling
- Computer Graphics
- Animation

## Features

- 2D input processing
- 3D model generation
- Transformation pipeline
- Animation sequences:
  - Walking
  - Running
  - Jumping

## Tools Used

- Python
- OpenCV
- Blender
- Unity
